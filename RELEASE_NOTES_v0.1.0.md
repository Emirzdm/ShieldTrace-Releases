# ShieldTrace v0.1.0 Beta

**Release date:** 5 August 2026
**Platform:** Windows x64
**Distribution:** Free proprietary beta

## Highlights

- Frequency-sweep absorption loss analysis
- Skin depth analysis
- Built-in reference materials and custom material support
- Full-size interactive chart tabs
- Deterministic technical analysis report
- PDF report export
- Turkish and English live interface
- Dark and light themes
- Portable Windows onedir package

## Installation

Download `ShieldTrace-v0.1.0-beta-Windows-x64.zip`, extract the entire archive and run `ShieldTrace.exe`.

The EXE must remain beside the `_internal` directory. Do not distribute or copy the EXE by itself.

The binary is currently unsigned. Windows may display an unknown publisher or SmartScreen warning. Only run packages obtained directly from the official ShieldTrace release repository.

## Known Limitations

- Good conductor approximation only
- Absorption component only
- No reflection-loss calculation
- No multiple-reflection calculation
- No total shielding-effectiveness calculation
- No real geometry or aperture modeling
- No installer or code signing
