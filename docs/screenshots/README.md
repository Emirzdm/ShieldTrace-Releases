# ShieldTrace v0.2.0 Showcase Screenshots

This directory is reserved for genuine screenshots of the running ShieldTrace
application. No screenshots are included yet. This guide is not an application
image or a substitute for one.

## Recommended Views

| View | What to show |
|---|---|
| Main measurement/research workspace | Sample and measurement organization, explicit measurement selection and visible workflow context. |
| Measured-data analysis / plot view | Imported measured points, readable frequency units, selected metrics and plot inspection. |
| Experiment trend or repeatability workflow | An explicitly selected experiment set or repeatability group, with descriptive results and relevant limitations visible. |
| Report / research export view | The actual export interface or an application-generated report preview, showing its research context. |

## Capture Guidelines

- Capture the actual v0.2.0 application. Do not fabricate screenshots, mock application
  output or add placeholder graphics that could be mistaken for working UI.
- Use authorized, non-sensitive data. Clearly label synthetic demonstration data
  in captions; do not present them as real laboratory VNA measurements.
- Remove personal information, private file paths and confidential sample or
  customer identifiers before capture.
- Prefer a consistent language and theme for the main set; optional additional
  captures may demonstrate Turkish / English and Light / Dark / System support.
- Keep labels, units, legends and applicable limitations readable. Crop for clarity
  without hiding warnings or changing the meaning of the results.
- Add a short factual caption and descriptive alt text when placing genuine images
  in the main README. Identify the application version and the demonstrated workflow.
- For research export, do not imply that a bundle can be independently rerun
  without the original source measurement data.

Screenshots demonstrate interface and workflow only. They do not establish
calibration, certified accuracy, laboratory validation or regulatory compliance.
